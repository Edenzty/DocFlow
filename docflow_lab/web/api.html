DocFlow 本地 API

单用户、本机运行。默认离线模拟；真实生成需要服务以 serve --live 启动，并在请求中指定 live: true。所有 POST 请求均需头 X-DocFlow-Local: 1，JSON 请求同时使用 Content-Type: application/json。

完整 OpenAPI JSON · 本页无需 CDN 或外部脚本，接口操作可使用 PowerShell、HTTP 客户端或项目工作台。

方法路径请求 / 用途
GET/api/config当前模型、预算、索引可用性
POST/api/search{"query":"设备返回403怎么排查？","method":"keyword"}
POST/api/search/compare{"query":"设备返回403怎么排查？"}；三路检索，失败分开报告，0次模型请求
GET/api/knowledge文档目录、来源、版本及章节数量
GET/api/tickets?status=awaiting_review&q=403&limit=50工单队列与筛选
POST/api/jobs{"question":"key-a访问device-b为什么403？","method":"keyword","strategy":"agent","live":false}；返回202和任务编号
GET/api/jobs/{id}排队、运行、完成、失败或中断状态
POST/api/jobs/{id}/retry{}；明确重试当前版本失败或中断任务
POST/api/tickets{"question":"设备返回403怎么排查？","method":"keyword","live":false}
GET/api/tickets/{id}读取工单、草稿、引用、审批、回复与事件
POST/api/tickets/{id}/draft{"method":"keyword","live":false}；新版本清除旧审批
POST/api/tickets/{id}/followups{"message":"补充：reason为device_forbidden","strategy":"agent","live":false}；保存对话并生成新版本
POST/api/tickets/{id}/edit{"version":1,"answer":"人工核对后的回复"}；无模型调用，新版本需重新审核
POST/api/tickets/{id}/review{"version":1,"approved":true}；仅批准该版本，不提交
POST/api/tickets/{id}/submit{"version":1,"simulate_timeout":false}；写入本地模拟回复
POST/api/tickets/{id}/retry{}；从失败步骤恢复

PowerShell：先做一次无模型调用的检索

$payload = @{query='设备A访问设备B为什么403？'; method='keyword'} | ConvertTo-Json
Invoke-RestMethod -Uri 'http://127.0.0.1:8765/api/search' -Method Post -ContentType 'application/json; charset=utf-8' -Headers @{'X-DocFlow-Local'='1'} -Body ([System.Text.Encoding]::UTF8.GetBytes($payload))

常见错误：403表示请求来源或本地头不符合要求；409表示审批、版本、状态或预算冲突；422表示请求结构错误；503表示检索不可用；504可能表示本地回复已写成但响应超时，此时读取工单后重试，不能假设没有写入。

POST 创建成功也应检查返回的 status：generation_failed 是已保存的失败工单，需要排查后重试。引用存在只代表片段编号有效，人工仍须核对回复内容。
